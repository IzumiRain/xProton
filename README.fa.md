## ✨ این چیه؟

**xProton** روی یک سرور لینوکس، **۱۰ لوکیشن پروتون‌وی‌پی‌ان** را اجرا می‌کند که
هرکدام روی یک **پورت SOCKS5 ثابت روی `127.0.0.1`** بایند شده‌اند. یک اکانت → یک
تانل → یک پورت؛ یعنی هم‌زمان ۱۰ کشور داری و می‌توانی هر برنامه را از مسیر دلخواه
بفرستی.

```
xproton                # پنل تعاملی (xproton / xpt / xpn هرسه کار می‌کنند)
sudo xproton start all # پروویژن + استارت همه‌ی لوکیشن‌ها
xproton test US        # 127.0.0.1:64210 تأخیر 425ms خروجی 72.251.221.12
```

### 📍 لوکیشن‌ها و پورت‌های ثابت

| لوکیشن | SOCKS5 | لوکیشن | SOCKS5 |
|---|---|---|---|
| 🇨🇦 کانادا | `127.0.0.1:64201` | 🇳🇴 نروژ | `127.0.0.1:64206` |
| 🇨🇭 سوئیس | `127.0.0.1:64202` | 🇵🇱 لهستان | `127.0.0.1:64207` |
| 🇯🇵 ژاپن | `127.0.0.1:64203` | 🇷🇴 رومانی | `127.0.0.1:64208` |
| 🇲🇽 مکزیک | `127.0.0.1:64204` | 🇸🇬 سنگاپور | `127.0.0.1:64209` |
| 🇳🇱 هلند | `127.0.0.1:64205` | 🇺🇸 آمریکا | `127.0.0.1:64210` |

هر **۱۰ کشور تیر فری** پوشش داده می‌شود. پورت‌ها پیش‌فرض `64201–64210` هستند
(بسته به لوکیشن) و از پنل یا دستور `xproton port` قابل تغییرند.

## 🧪 نتیجه‌ی تست فشار (Live)

> این‌ها نتایج واقعی یک تست بار روی یک **VPS ساعتی** (Ubuntu 24.04، ۱vCPU /
> ۲GB RAM) روی تیر فری پروتون است.

| معیار | نتیجه |
|---|---|
| لوکیشن‌های تست‌شده | **۱۰ از ۱۰، هم‌زمان** |
| ترافیک دانلودی مصرف‌شده | **≈ ۳ ترابایت (≈ 2.9 × 10¹² بایت)** |
| نرخ اوج | چند گيگابیت بر ثانیه روی ۱۰ تانل |
| کانکشن موازی به‌ازای هر اکانت | **۳** (تا ببینیم اکانت بن می‌شود یا نه) |
| اکانت‌های بن‌شده | **صفر ✅** |

**نتیجه‌ای که گرفتیم:**

1. **پروتون اکانت فری را به‌خاطر مصرف سنگین دانلود بن نمی‌کند** — حتی بعد از
   تقریباً ۳ ترابایت ترافیک مداوم با چند کانکشن موازی روی یک اکانت. مصرفِ زیادِ
   پهنای‌باند چیزی نیست که آنتی‌ابیوز پروتون را فعال کند.
2. **چیزی که ریسک بن دارد، خودِ ثبت‌نام است، نه مصرف:** ساخت انبوه اکانت از یک
   IP (کپچا / خطای 9001)، چند کانکشن مشترک روی یک اکانت، و اتوماسیون خلاف ToS
   بک‌اند اکانت موقت. به همین دلیل xProton ساخت اکانت را **با فاصله** انجام
   می‌دهد و برای ساخت انبوه **چرخش پروکسی** دارد.
3. بعد از تست، هر ۱۰ لوکیشن سالم ماندند — همان IP های خروجی، تأخیر کم، تانل
   برپا.

> **تفسیر:** تا وقتی که مصرف‌کننده‌ی «تقریبا معمولیِ» پهنای‌باند باشی xProton
> کاربردی است. این ابزار برای سوءاستفاده‌ی بی‌نهایت ترابایتی طراحی نشده؛ به محض
> اینکه شروع کنی به ساخت اکانت موقت پشت‌سرهم یا فشار حجم عجیب از یک IPِ فلگ‌شده،
> پروتون می‌تواند اکانت‌ها را قطع کند.

### ⚙️ چطور خودت تکرار کنی

```bash
# روی سرور، بعد از نصب و `xproton start all`:
bash tools/stress-test.sh 1000     # هر ۱۰ پورت، ۱ گیگابایت دانلود
tail -f /run/xproton-stress/results.log
bash tools/stress-test.sh stop     # توقف همه
```

> ⚠️ کشیدن ترابایت روی VPSِ کُنت‌دار هزینه‌ی egress واقعی دارد. ما این را روی
> یک سرور ساعتی اجرا کردیم و قبل از مهم‌شدن متوقفش کردیم.

## 🚀 نصب با یک خط

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/IzumiRain/xProton/main/install.sh)
```

این یک خط کارهای زیر را می‌کند: نصب پیش‌نیازها، دانلود باینریِ ثابتِ
`sing-box` (GPL-3.0، به‌عنوان برنامه‌ی خارجی)، نصب دستورهای `xproton` / `xpt`
/ `xpn`، قالب سرویس systemd `xproton@.service` و قالب `accounts.txt`.

```bash
sudo xproton doctor          # بررسی سلامت
xproton create               # ساخت اکانت API (با پشتیبانی پروکسی)
sudo xproton start all       # پروویژن + استارت همه
xproton status               # جدول وضعیت
xproton test all --speed     # تأخیر / IP خروجی / سرعت
```

## ⚠️ هشدارها — اول این را بخوان

این پروژه **فقط برای اهداف آموزشی و تحقیقاتی** است. قبل از استفاده کامل بخوان —
مسئولیت هر کاری که با آن می‌کنی با خودت است.

1. **با ریسک خودت استفاده کن.** هیچ ارتباطی با Proton AG نداریم. پروتون‌وی‌پی‌ان
   علامت تجاری Proton AG است.
2. **نقض ToS پروتون.** پروویژنر داخلی ساخت اکانت را خودکار می‌کند که خلاف شرایط
   خدمات پروتون است. اکانت‌ها هر لحظه و بدون هیچ پشتوانه‌ای ممکن است بن شوند.
3. **برای کار خلاف قانون نیست.** ترافیک خروجی از سرورهای فری پروتون می‌گذرد که
   سیاست لاگ/سوءاستفاده‌ی خودشان را دارند. اگر از این ابزار قانون را بشکنی،
   مسئولیت‌ش با خودت است.
4. **هیچ تضمینی / بدون SLA.** اکانت موقت ممکن است کار نکند، بک‌اند سشنِ شخص
   ثالث ممکن است محدود یا ناپدید شود، و پول کشورهای فری می‌گردد. تانل‌ها می‌توانند
   بی‌صدا بمیرند.
5. **ریسک کپچا / بن IP.** ساخت اکانت زیاد یا لاگین از یک IP دیتاسنتر می‌تواند
   آنتی‌ابیوز پروتون را فعال کند. این ابزار ساخت را با فاصله انجام می‌دهد و برای
   ساخت انبوه لیست پروکسی می‌پذیرد — ولی هیچ تضمینی نیست.
6. **عواقبش مال خودت.** اگر روی یک سرور پروداکشن اجراش کنی یا به آن برای چیز
   مهمی تکیه کنی، با خودت. این یک ابزار **بتا** است.
7. **هزینه‌ی ترافیک کُنت‌دار.** تست فشار می‌تواند قبض egress واقعی روی
   VPSِ کُنت‌دار تولید کند. مواظب باش.

## 🛠️ مرجع دستورها

| دستور | کار |
|---|---|
| `xproton` (یا `xpt`, `xpn`) | پنل تعاملی |
| `xproton status` | جدول وضعیت لوکیشن‌ها |
| `xproton locations` | لیست لوکیشن‌ها + پورت‌های ثابت |
| `sudo xproton start [US\|all]` | پروویژن + استارت |
| `sudo xproton stop / restart [US\|all]` | توقف / ری‌استارت |
| `xproton logs US [-f] [-n 100]` | لاگ‌های journald |
| `xproton test [US\|all] [--speed]` | تأخیر / IP خروجی / سرعت |
| `xproton create [--count N] [--proxy-file F]` | ساخت اکانت API (بدون پروکسی ۱۰، با پروکسی ۵۰) |
| `xproton verify [--proxy-file F]` | بررسی اکانت‌ها + تمدید سرتیفیکیت‌های رو به انقضا |
| `sudo xproton provision [US\|all] [--provider auto\|manual\|temp]` | ساخت مجدد اکانت/سرتیفیکیت |
| `sudo xproton port US --socks 64210` | تغییر پورت SOCKS یک لوکیشن |
| `xproton accounts` | نمایش accounts.txt + نقشه‌ی تخصیص |
| `sudo xproton autostart on\|off\|status` | استارت هنگام بوت |
| `sudo xproton doctor` | بررسی سلامت |
| `sudo xproton update [--check]` | آپدیت از گیت‌هاب |
| `sudo xproton uninstall [--purge] [--yes]` | حذف xProton |

## 🔑 اکانت‌ها

همه‌ی اکانت‌ها در یک فایل، `/etc/xproton/accounts.txt` (فقط root، 0600)،
به‌صورت **بلوک دوخطی**:

```text
# اکانت دستی (خودت در account.proton.me ساخته‌ای — free forever):
myname@proton.me:S3cretPass:JBSWY3DPEHPK3PXP:JP
{"uid":"...","accessToken":"..."}

# اکانت ساخته‌شده با API (موقت، بک‌اند credential نمی‌دهد):
api:tmp-3f9a2c71:US
{"uid":"...","accessToken":"...","refreshToken":"..."}
```

- **دستی** — دائمی و مال خودت (free forever).
- **API** — credential ندارد (بک‌اند نمی‌دهد)، پس به بک‌اند اکانت موقت وابسته است
  و ممکن است هر لحظه بمیرد؛ وقتی سشن ذخیره‌شده بمیرد، xProton **self-heal**
  می‌کند (اکانت جدید می‌سازد).
- سرتیفیکیت‌ها (~۱ سال) توسط `xproton verify` قبل از انقضا خودکار تمدید می‌شوند.
- اکانت پین‌شده به یک کشور، همان لوکیشن را پر می‌کند؛ بقیه به ترتیب لوکیشن‌های
  باقی‌مانده؛ مازاد **اسپیر** می‌شود (برای وقتی اکانتِ یک لوکیشن بن شود).

### لیست پروکسی برای ساخت اکانت

لیست‌های رایگان پروکسی مستقیم کار می‌کنند (خط‌های ساده `ip:port`)، مثلاً از
[monosans/proxy-list](https://github.com/monosans/proxy-list)،
[TheSpeedX/PROXY-List](https://github.com/TheSpeedX/PROXY-List) یا
[proxifly/free-proxy-list](https://github.com/proxifly/free-proxy-list):

```text
# proxies.txt — هر خط یک پروکسی، خط‌های (#) نادیده گرفته می‌شوند
socks5://user:pass@1.2.3.4:1080
socks4://5.6.7.8:1080
http://9.9.9.9:3128
31.76.80.215:1080          # ip:port ساده = socks5
```

`xproton create` اول می‌پرسد لیست پروکسی داری یا نه، بعد تعداد اکانت. سقف:
**۱۰ اکانت** بدون لیست پروکسی، **۵۰** با آن. پروکسی مرده خودکار رد می‌شود.

## 🏗️ طرز کار

- **هر لوکیشن = یک اکانت = یک تانل = یک پورت SOCKS5.** تیر فری پروتون فقط
  **۱ کانکشن به‌ازای هر اکانت** می‌دهد؛ پس هر لوکیشن اکانت مستقل خودش را دارد.
- **دو منبع اکانت:** API (خودکار، موقت) یا دستی (مال خودت).
- **تانل‌ها در userspace** با endpoint های `wireguard` سینگ‌باکس اجرا می‌شوند —
  بدون ماژول کرنل، بدون تداخل مسیر بین ۱۰ تانل.
- **DNS از داخل تانل** (10.2.0.1) رزولوشن می‌شود — یعنی DNS هم از IP همان
  لوکیشن خارج می‌شود.

```
 apps ─► 127.0.0.1:64210 (socks5, US) ──► sing-box ──► Proton US-FREE
 apps ─► 127.0.0.1:64205 (socks5, NL) ──► sing-box ──► Proton NL-FREE
 apps ─► 127.0.0.1:64201 (socks5, CA) ──► sing-box ──► Proton CA-FREE
```

## ❓ رفع اشکال

| مشکل | علت / راه‌حل |
|---|---|
| `Proton API error 9001` | کپچا. صبر کن، اکانت یا IP عوض کن. |
| `Proton API error 5003` | نسخه‌ی اپ قدیمی → در config.json مقدار `app_version` را ست کن |
| `Proton API error 8001` | رمز/ایمیل اشتباه در accounts.txt |
| `Proton API error 10013` | اکانت حالت دو-پسورد دارد → تک-پسورد کن |
| `no free server available in X` | پول کشورهای فری چرخیده؛ لوکیشن دیگری امتحان کن |
| `xproton test` چیزی نمی‌شنود | یونیت کرش کرده → `xproton logs US`؛ یا پورت عوض شده |
| خطای بک‌اند در provider موقت | بک‌اند شخص ثالث پایین/محدود → از اکانت دستی استفاده کن |
